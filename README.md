# 9 Square Infra – Estimates, Quotations & Agreements

Private dashboard for preparing estimates, quotations and agreement letters.

## GitHub Pages

1. Upload the contents of this folder to the `main` (or `gh-pages`) branch of `9SquareInfra/Dashboard`.
2. In the repo **Settings → Pages**, set Source to that branch, folder `/` (root).
3. Site URL will be `https://9squareinfra.github.io/Dashboard/` (or the custom domain you set).

No build step. Open `index.html` locally or via Pages.

## Files

- `index.html` – shell
- `styles.css` – dark / gold theme matching 9squareinfra.github.io
- `app.js` – full app (localStorage persistence)
- `assets/logo.png` – company logo

Documents are stored in the browser (`localStorage`). Use **Export / Import backup** on the Documents tab.
